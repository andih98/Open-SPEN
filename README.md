# Open-SPEN: Spatiotemporal Encoding Implementation in Pulseq

This repository provides example **SPEN-SE-EPI** and **Multi-Slice DW-SPEN-SE-EPI** Pulseq sequences, including educational code for the derivation of SPEN's **Forward Operator** and basic image reconstruction.

---
